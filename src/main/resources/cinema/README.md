# Cinema Ticket Booking

Мини-проект СРО №1 по дисциплине «Визуальное программирование» (вариант 10).
Настольное приложение на **Java + JavaFX + FXML (Scene Builder)** для продажи билетов в кинотеатре:
фильмы, сеансы, выбор мест на схеме зала и расчёт стоимости.

## Запуск

Требуется **JDK 17+** и **Maven 3.8+** (JavaFX подтягивается через Maven).

```bash
mvn javafx:run     # запустить приложение
mvn test           # запустить тесты расчёта стоимости
```

В IntelliJ IDEA: открыть папку как Maven-проект, в панели Maven выбрать
`Plugins → javafx → javafx:run`.

## Возможности

- Таблица фильмов: название, жанр, длительность, возраст, цена. Сортировка по клику на заголовок.
- Добавление, редактирование (форма или двойной клик), удаление фильмов.
- Поиск по названию и фильтр по жанру (работают вместе).
- Список сеансов выбранного фильма: добавление (дата, время, зал) и удаление.
- Окно выбора мест: схема зала 6×8, занятые места недоступны, последний ряд — VIP (+50%).
- Расчёт стоимости: тип билета (взрослый / студенческий −30% / детский −50%) и VIP-наценка.
- Строка состояния со статистикой: фильмы, сеансы, проданные билеты.
- Данные сохраняются в CSV в папке `~/.cinema-booking/`; при первом запуске создаются 12 фильмов и 36 сеансов.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+N | Добавить фильм |
| Ctrl+E | Изменить фильм |
| Ctrl+D | Удалить фильм |
| Ctrl+B | Купить билеты |
| Ctrl+T | Добавить сеанс |
| Ctrl+F | Перейти к поиску |
| Ctrl+S | Сохранить |
| Ctrl+Q | Выход |

## Структура проекта

```
src/main/java/cinema/
├── App.java                      точка входа
├── model/   Movie, Screening, TicketType
├── data/    DataStore            хранилище, CSV, демо-данные
├── util/    PriceCalculator      расчёт стоимости билета
└── controller/
    ├── MainController            главное окно
    ├── MovieFormController       форма фильма
    └── SeatController            выбор мест и покупка
src/main/resources/cinema/
├── main.fxml, movie_form.fxml, seats.fxml
└── style.css
src/test/java/cinema/util/PriceCalculatorTest.java
```

## Соответствие требованиям СРО

| Требование | Реализация |
|---|---|
| Интерфейс в Scene Builder / FXML, логика в Controller | `*.fxml` + `controller/*` |
| ≥ 2 layout-контейнеров, ≥ 5 типов Controls | BorderPane, VBox, HBox, SplitPane, GridPane; Button, Label, TextField, ComboBox, TableView, ListView, ToggleButton, DatePicker, MenuBar, ToolBar |
| TableView/ListView, ≥ 10 записей | таблица фильмов (12), список сеансов |
| Добавление, редактирование, удаление, поиск, фильтрация | `MainController`, `MovieFormController` |
| MenuBar, ToolBar, строка состояния, ≥ 2 горячих клавиш | `main.fxml` (8 горячих клавиш) |
| ≥ 2 окна, навигация, диалоги Alert | главное окно → форма фильма → окно выбора мест |
| Проверка ввода без аварийных завершений | `MovieFormController.onSave`, диалог нового сеанса, обработка ошибок CSV |
| Локальное хранение CSV | `DataStore` |
